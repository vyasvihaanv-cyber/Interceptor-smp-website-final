How To Connect

Join Interceptor in under two minutes from Java Edition or Bedrock Edition.

J

Minecraft Java Edition

  1. 1 Launch Minecraft Java and click on Multiplayer.
  2. 2 Click on Add Server at the bottom.
  3. 3 Set Server Name to Interceptor MC.
  4. 4
    Enter Server Address:
    play.interceptor.dpdns.org
B

Bedrock (Windows, iOS, Android, Consoles)

  1. 1 Launch Minecraft and click Play → Servers Tab.
  2. 2 Scroll down and select Add Server.
  3. 3 Enter Address: play.interceptor.dpdns.org
  4. 4 Default Port: 19132 (or default standard). Click Save & Join!

Server Rules
